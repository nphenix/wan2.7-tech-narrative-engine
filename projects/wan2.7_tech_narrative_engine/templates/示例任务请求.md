# 示例任务请求

以下内容可作为比赛任务的起始模板。

```md
# user_request

- 比赛任务目标：生成面向评委的视频作品
- 目标评委或观众：比赛评委与技术观众
- 必须出现的对象：Wan2.7、CoPaw、AgentScope
- 必须避免的风险：空洞口号、结构失真、技术概念堆砌
- 结尾收束要求：自然收束到成为 AI 时代的参与者
```

## 使用建议

- 先由 `wan2.7_tech_narrative_engine_intake_skill` 初始化任务目录
- 再将本模板内容补入 `input/user_request.md`
- 再依次运行 `strategy_skill` 与 `draft_skill`
